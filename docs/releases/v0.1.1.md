# Portskill 0.1.1

Portskill is a local port registry for developers and AI agents. Reserve project
port ranges, start and stop services, and manage them through an HTML dashboard,
MCP, or the Python CLI.

## Highlights

- Shared port allocation, saved service commands, startup defaults, and workspace
  import/export.
- HTTP and stdio MCP, per-tool controls, command chains, and `full` / `lean` profiles.
- Optional Tailscale Serve for registered services and an optional passkey gate
  for the local dashboard.
- Cleaner setup documentation, fresh-clone Mac build scripts, and verified Python
  source/wheel installations.
- HTTP Host validation and browser-origin checks for the local listener.

## Experimental (Beta)

**Session Handoff is disabled by default.** Enable it in the dashboard's
**Experimental (Beta)** section to make its tools available. While disabled,
Handoff tools are hidden from MCP, direct and chained calls are rejected, and the
dashboard does not read the handoff ledger.

Agent hooks require a separate installation. Disabling Portskill's integration
does not uninstall hooks or browser extensions already installed elsewhere.

## Install

Requires **Python 3.10+** on **macOS or Linux**. There are no third-party Python
runtime dependencies. Tailscale is optional.

### Run from source

Download `portskill-0.1.1.tar.gz` below, then:

```bash
tar -xzf portskill-0.1.1.tar.gz
cd portskill-0.1.1
./scripts/run.sh
```

The server prints its URL and opens the dashboard. Add `--no-open` to skip opening
a browser. The listen port is allocated automatically and reused when available.

### Install the wheel

Download `portskill-0.1.1-py3-none-any.whl` below, then:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./portskill-0.1.1-py3-none-any.whl
portskill
```

For CLI health checks, run `portskill-cli doctor`. Source includes the optional
Handoff kit and Mac build scripts. Wheel and Mac installations need an explicit
path to the source kit to enable Handoff; see the
[setup instructions](https://github.com/bens27/Portskill/blob/v0.1.1/README.md#experimental-beta).

## Defaults and limitations

Portskill is early-stage software for personal development machines. The default
listener is `127.0.0.1`. Local HTTP access is open unless you enable the optional
passkey gate. Service commands run with your account's permissions. Tailscale
sharing does not add HTTP authentication.

**Stop also Release** is on by default; turn it off to keep reservations after
stopping a service. Existing explicit Handoff or Tailscale Serve settings are
preserved when upgrading.

No signed or notarized Mac binary is supplied. Remote machine management and
multi-user access are not implemented. Read the
[security policy](https://github.com/bens27/Portskill/blob/v0.1.1/SECURITY.md)
before changing network exposure.

## Downloads and verification

| File | Contents |
| --- | --- |
| `portskill-0.1.1.tar.gz` | Source, docs, tests, Mac build scripts, and optional Handoff kit |
| `portskill-0.1.1-py3-none-any.whl` | Installable core Python application and static assets |
| `SHA256SUMS` | SHA-256 checksums for the two packages |

After downloading all three files into one directory, verify the packages:

```bash
# macOS
shasum -a 256 -c SHA256SUMS
# Linux
sha256sum -c SHA256SUMS
```

The checksum file detects changed or incomplete downloads; it is not a code
signature. See the [changelog](https://github.com/bens27/Portskill/blob/v0.1.1/CHANGELOG.md)
for changes since the private 0.1.0 build.
